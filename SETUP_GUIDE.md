# 🚀 How to Set Up Your GitHub Profile README

## Step 1: Create the Special Repository

1. Go to [GitHub](https://github.com) → Click **"New"** (green button)
2. Set **Repository name** to exactly: `deepakk789`
   > ⚠️ This MUST match your username exactly — GitHub recognizes this as your profile repo
3. Set it to **Public**
4. **Do NOT initialize** with README (we'll push ours)
5. Click **Create repository**

---

## Step 2: Push the README

Open **PowerShell** or **Git Bash** in the `d:\github profile\` folder and run:

```powershell
cd "d:\github profile"

git init
git add .
git commit -m "feat: add stunning GitHub profile README with animations"
git branch -M main
git remote add origin https://github.com/deepakk789/deepakk789.git
git push -u origin main
```

---

## Step 3: Enable Snake Animation (Optional but 🔥)

After pushing, go to your repo on GitHub:

1. Go to **Settings** → **Actions** → **General**
2. Under **Workflow permissions**, select **Read and write permissions**
3. Click **Save**
4. Go to **Actions** tab → Click **Generate Snake Animation** → Click **Run workflow**

The animated snake will start appearing on your profile after the first run!
